# Astrabeam website

Marketing site for [Astrabeam](https://www.astrabeam.com): perception for physical AI.
Plain HTML, CSS and JavaScript. No build step and no dependencies to install.

## Run locally

```bash
python3 serve.py        # http://localhost:5173
```

`serve.py` is a tiny static server with HTTP Range support. Safari needs Range
support to play `<video>`, which Python's built-in `http.server` lacks.

## Layout

| File | What it does |
|------|--------------|
| `index.html` | All page sections and copy |
| `styles.css` | Styles. Colors are CSS variables at the top (`--accent` is brand orange `#FF6600`) |
| `main.js` | Hero and flight video controls, phone menu, scroll reveals, diagram animation pausing |
| `flight.js` | "In the field" replay: synced camera video + Three.js 3D view of a recorded flight |
| `privacy.html`, `404.html` | Privacy page; not-found page (GitHub Pages serves it for missing URLs) |
| `assets/` | Logo variants, hero video (1080p + 720p) and poster, `og-image.jpg` link preview |
| `assets/team/` | Team headshots, 480×480 JPG (shown grayscale, color on hover) |
| `assets/pov/` | Basement flight dashboard video (loads only when scrolled into view) |
| `assets/flight/` | Recorded flight replay: `replay.mp4` (camera + depth) and `flight.json` (per-sample obstacles, paths, telemetry) |

## Editing

- **Copy:** edit text directly in `index.html`.
- **Team:** add a 480×480 JPG to `assets/team/` and copy one `<figure class="person">` block in `index.html`.
- **Hero video:** replace `assets/hero-1080.mp4`, `assets/hero-720.mp4` and `assets/hero-poster.jpg`. Keep them H.264 MP4 and silent. On a Mac (no ffmpeg needed):

  ```bash
  swift tools/video.swift info   ~/Downloads/new.mp4
  swift tools/video.swift encode ~/Downloads/new.mp4 assets/hero-1080.mp4 1920 1080 4500000
  swift tools/video.swift encode ~/Downloads/new.mp4 assets/hero-720.mp4  1280 720  2200000
  swift tools/video.swift poster assets/hero-1080.mp4 assets/hero-poster.jpg 0.3
  ```
- **Flight replay:** `flight.json` is in a robot-centred, yaw-stabilised body frame (x forward, y left, z up); `flight.js` converts it for Three.js. Video frame *i* matches sample *i* at `meta.hz`.

## Notes

- The flight replay shows the drone's onboard depth camera, not Astrabeam radar.
- The platform diagrams are illustrations generated by `tools/platform_diagrams.py`; they carry no performance figures.
